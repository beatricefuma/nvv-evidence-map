# Interactive evidence map

Interactive evidence map accompanying the scoping review:

Affective Nonverbal Vocalizations and Implications for Cochlear Implants: A Scoping Review

The map summarizes study-level cue-outcome evidence linking acoustic features of adult nonverbal vocalizations to affective and salience-related perception, including cochlear implant and cochlear implant simulation evidence.

The file is a self-contained HTML page hosted with GitHub Pages.
